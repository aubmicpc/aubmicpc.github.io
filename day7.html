A

The Bottles

Queries

Many problems give you an array and then a list of queries: small instructions that each change the array or ask something about it. Handle them one at a time, in the order they're given. Read a query, apply it, print what it asks for, and only then move on to the next one:

while (q--) {
    // read one query, apply it, print the result
}

This is the same while (q--) loop used for test cases, but with one important difference: the array is not reset between queries. Every swap is done on the array as the previous queries left it, which is why the second line of the first sample starts from 3 1 2 4 5 and not from the original array.

The swap itself is done with swap from Day 5, which works on array elements too.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    while (q--) {
        int x, y;
        cin >> x >> y;
        swap(a[x - 1], a[y - 1]);
        for (int i = 0; i < n; i++) {
            cout << a[i] << " ";
        }
        cout << "\n";
    }
    return 0;
}

For each query, swap the two bottles, then print the whole array.

B

Minimize Number

Looking at one number at a time

The operation divides every number by 2 together, and it stops as soon as any one of them becomes odd. So instead of simulating the whole array, look at each number on its own and count how many times it can be divided by 2 before it becomes odd:

int count = 0;
while (x % 2 == 0) {
    x /= 2;
    count++;
}

For the first sample, 8 can be halved 3 times, 12 can be halved 2 times, and 40 can be halved 3 times.

The answer is the minimum

The operations stop as soon as the number with the smallest count runs out. In the first sample that's 12, which becomes odd after 2 halvings, so the answer is 2 even though 8 and 40 could go further.

So the answer is the smallest count over all the numbers. Keep it in a variable that starts very large and update it with min after each number.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int ans = 100;
    for (int i = 0; i < n; i++) {
        int count = 0;
        while (a[i] % 2 == 0) {
            a[i] /= 2;
            count++;
        }
        ans = min(ans, count);
    }
    cout << ans << "\n";
    return 0;
}

Count how many times each number can be halved and print the smallest count. ans starts at 100, which is bigger than any possible count (a number up to 109 can be halved at most 29 times).

C

Matrix

2D arrays

A 2D array, or matrix, is an array of rows, where each row is itself an array. With vectors, an N × N matrix is written as:

vector<vector<int>> a(n, vector<int>(n));

a[i][j] is the element in row i and column j, both starting at 0. To read the matrix, use two nested loops, one for the rows and one for the columns:

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cin >> a[i][j];
    }
}

The diagonals

The primary diagonal goes from the top left to the bottom right. Its elements are the ones where the row and column are equal: a[0][0], a[1][1], and so on up to a[n - 1][n - 1].

The secondary diagonal goes from the top right to the bottom left. In row i, its element is in column n - 1 - i: a[0][n - 1], a[1][n - 2], and so on up to a[n - 1][0].

So a single loop over i can add up both diagonals at the same time.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> a[i][j];
        }
    }

    int primary = 0, secondary = 0;
    for (int i = 0; i < n; i++) {
        primary += a[i][i];
        secondary += a[i][n - 1 - i];
    }
    cout << abs(primary - secondary) << "\n";
    return 0;
}

Add up a[i][i] and a[i][n - 1 - i] for every row, then print the absolute difference of the two sums.

D

Palindrome Array

Comparing from both ends

An array is a palindrome when the first element equals the last, the second equals the second to last, and so on. The element matching a[i] from the other end is a[n - 1 - i], just like the secondary diagonal in Matrix.

bool flags

A bool is a type that holds only true or false. It's useful for remembering whether something happened while going through an array. Start by assuming the array is a palindrome, and change your mind if you find a pair that doesn't match:

bool palindrome = true;
for (int i = 0; i < n; i++) {
    if (a[i] != a[n - 1 - i]) palindrome = false;
}

A variable used like this is called a flag. After the loop, if (palindrome) is true only if every pair matched. != means “not equal”.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    bool palindrome = true;
    for (int i = 0; i < n; i++) {
        if (a[i] != a[n - 1 - i]) palindrome = false;
    }

    if (palindrome) cout << "YES" << "\n";
    else cout << "NO" << "\n";
    return 0;
}

Compare every element with the one at the same distance from the other end. If any pair differs, the array is not a palindrome.
