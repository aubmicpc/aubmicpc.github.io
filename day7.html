A

The Bottles

1-indexed positions

The positions in the queries start at 1, but array indexes start at 0. Position x in the statement is a[x - 1] in the array, so subtract 1 before using it.

To swap the two bottles, use swap from Day 5. It works on array elements too:

swap(a[x - 1], a[y - 1]);

After each query, print the whole array on its own line.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    while (q--) {
        int x, y;
        cin >> x >> y;
        swap(a[x - 1], a[y - 1]);
        for (int i = 0; i < n; i++) {
            cout << a[i] << " ";
        }
        cout << "\n";
    }
    return 0;
}

For each query, swap the elements at indexes x - 1 and y - 1, then print the array.

B

Minimize Number

bool flags

A bool is a type that holds only true or false. It's useful for remembering whether something happened while going through an array. To check that all numbers are even, start by assuming they are, and change your mind if you find an odd one:

bool allEven = true;
for (int i = 0; i < n; i++) {
    if (a[i] % 2 == 1) allEven = false;
}

A variable used like this is called a flag. After the loop, if (allEven) runs only if no odd number was found.

Repeating the operation

We don't know in advance how many times the operation can be done, so repeat it in a while (true) loop, which only ends with break. Each time, check the flag first. If an odd number was found, stop; otherwise divide every element by 2 and count one operation.

Each operation halves every number, and 109 can only be halved about 30 times, so the loop ends quickly.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int ops = 0;
    while (true) {
        bool allEven = true;
        for (int i = 0; i < n; i++) {
            if (a[i] % 2 == 1) allEven = false;
        }
        if (!allEven) break;

        for (int i = 0; i < n; i++) {
            a[i] /= 2;
        }
        ops++;
    }
    cout << ops << "\n";
    return 0;
}

Keep halving every element while they are all even, and count how many times you did it. !allEven means “not allEven”.

C

Matrix

2D arrays

A 2D array, or matrix, is an array of rows, where each row is itself an array. With vectors, an N × N matrix is written as:

vector<vector<int>> a(n, vector<int>(n));

a[i][j] is the element in row i and column j, both starting at 0. To read the matrix, use two nested loops, one for the rows and one for the columns:

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cin >> a[i][j];
    }
}

The diagonals

The primary diagonal goes from the top left to the bottom right. Its elements are the ones where the row and column are equal: a[0][0], a[1][1], and so on up to a[n - 1][n - 1].

The secondary diagonal goes from the top right to the bottom left. In row i, its element is in column n - 1 - i: a[0][n - 1], a[1][n - 2], and so on up to a[n - 1][0].

So a single loop over i can add up both diagonals at the same time.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> a[i][j];
        }
    }

    int primary = 0, secondary = 0;
    for (int i = 0; i < n; i++) {
        primary += a[i][i];
        secondary += a[i][n - 1 - i];
    }
    cout << abs(primary - secondary) << "\n";
    return 0;
}

Add up a[i][i] and a[i][n - 1 - i] for every row, then print the absolute difference of the two sums.

D

Palindrome Array

Comparing from both ends

An array is a palindrome when the first element equals the last, the second equals the second to last, and so on. The element matching a[i] from the other end is a[n - 1 - i], just like the secondary diagonal in Matrix.

Use a bool flag that starts as true, and set it to false if any pair doesn't match.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    bool palindrome = true;
    for (int i = 0; i < n; i++) {
        if (a[i] != a[n - 1 - i]) palindrome = false;
    }

    if (palindrome) cout << "YES" << "\n";
    else cout << "NO" << "\n";
    return 0;
}

Compare every element with the one at the same distance from the other end. If any pair differs, the array is not a palindrome.
