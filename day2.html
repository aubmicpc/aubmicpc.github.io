Reading input

Yesterday you only printed things. Today most problems give you input on standard input, which you read with cin (character input) and >>, chained the same way as cout:

int a; long long b;
cin >> a >> b; // reads two space/newline-separated values, in order

cin >> automatically skips spaces and newlines between values, so it doesn't matter whether the input is on one line or split across several — you just chain >> once per value, in the order they appear.

Practice

Three problems: reading typed values, using the last digit of a number, and doing arithmetic that doesn't overflow.

A. Basic Data Types

Time limit: 1 second · Memory limit: 256 MB

Statement

The following lines show some C++ data types:

  • int: 32-bit integer.
  • long long: 64-bit integer.
  • char: 8-bit character or symbol.
  • float: 32-bit real value.
  • double: 64-bit real value.

Input / Output

One line with five space-separated values A (int), B (long long), C (char), F (float), D (double), in that order. Print each on its own line, same order, no extra spaces.

−231 ≤ A ≤ 231−1 · −263 ≤ B ≤ 263−1 · C is a single printable character · −106 ≤ F ≤ 106 (≤3 decimals) · −109 ≤ D ≤ 109 (≤6 decimals)
InputOutput
3 12345678912345 a 334.23 14049.30493
 
3
12345678912345
a
334.23
14049.3

How to think about it

This problem is really about picking the right box for each value. int can only hold up to about 2.1 billion — B here is up to roughly 9.2×1018, which needs long long instead, or your program would silently produce garbage (this is called overflow).

Reading a char with cin >> c is safe here: it skips leading whitespace and then reads exactly one non-space character, so it correctly grabs a even though there are spaces before and after it in the input.

Why 14049.30493 prints as 14049.3

By default cout prints floating-point numbers with 6 significant digits total, not 6 digits after the point. 14049.30493 has 7 significant digits, so it gets rounded down to 14049.3 (6 significant digits). This is expected and accepted — the judge allows an absolute or relative error up to 10−5 on F and D, so printing more digits (e.g. with cout << setprecision(9)) is also fine.

Hints

Hint 1

Declare five variables with the five types named in the statement, in the same order they're read: int, long long, char, float, double.

Hint 2

One cin >> chain reads all five in order. One cout per variable (or one chain with "\n" between each) prints them back, each on its own line.

Hint 3

You don't need to do anything special for the default 6-significant-digit rounding — just cout << f and cout << d directly; the example output already reflects that default behaviour.

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a;
    long long b;
    char c;
    float f;
    double d;
    cin >> a >> b >> c >> f >> d;

    cout << a << "\n";
    cout << b << "\n";
    cout << c << "\n";
    cout << f << "\n";
    cout << d << "\n";
    return 0;
}
long long b;
Only type here big enough for values up to ~9.2×1018; int would overflow.
cin >> a >> b >> c >> f >> d;
Reads the five values in the exact order they appear on the input line.
cout << f; / cout << d;
Printed with cout's default formatting (6 significant digits), which matches what the judge expects and accepts.

B. Digits Summation

Time limit: 0.25 seconds · Memory limit: 64 MB

Statement

Given two numbers N and M. Print the summation of their last digits.

Input / Output

One line: N M with 0 ≤ N, M ≤ 1018
InputOutput
13 12
5

Last digit of 13 is 3, last digit of 12 is 2, so the answer is 3+2=5.

How to think about it

The "last digit" of a number is what's left over when you divide it by 10 — that's exactly what the modulo operator % gives you. N % 10 is the remainder of N divided by 10, which is precisely its last digit (for any non-negative N).

Watch out for

N and M go up to 1018, and int only safely holds up to about 2.1×109. Reading them into int would overflow and give wrong values before you even get to the %. Use long long for both.

Hints

Hint 1

You need the remainder when dividing by 10. C++'s operator for that is %.

Hint 2

Compute N % 10 and M % 10 separately, then add them together and print the sum.

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, m;
    cin >> n >> m;
    cout << (n % 10 + m % 10) << "\n";
    return 0;
}
long long n, m;
Both need to hold values up to 1018.
n % 10 + m % 10
Last digit of n plus last digit of m; the sum is at most 18, so it fits comfortably in any type.

C. Difference

Time limit: 1 second · Memory limit: 256 MB

Statement

Given four numbers A, B, C and D. Print the result of the following equation:

X = (A × B) − (C × D)

Input / Output

One line: A B C D with −105 ≤ A, B, C, D ≤ 105. Print "Difference = " followed by the result.
InputOutput
1 2 3 4
Difference = -10
2 3 4 5
Difference = -14
4 5 2 3
Difference = 14

How to think about it

Read the four numbers, compute A*B - C*D, and print it after the exact label "Difference = " (note the spaces around the equals sign).

Watch out for

With A, B up to 105 in size, A*B can be as large as 1010 — already bigger than int can hold (max ~2.1×109). If you store A, B, C, D as int and multiply, the multiplication overflows before it's ever assigned anywhere, giving a wrong answer that's hard to spot. Declare them as long long from the start so every intermediate result is safe.

Hints

Hint 1

Think about the largest possible value of A*B given the constraints, and compare it to what int can hold.

Hint 2

Declare all four variables as long long, then compute a*b - c*d directly — C++ respects normal operator precedence, so you don't need extra parentheses.

Hint 3

Print with cout << "Difference = " << x; — the label string already has the spaces the expected output needs.

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long a, b, c, d;
    cin >> a >> b >> c >> d;
    long long x = a * b - c * d;
    cout << "Difference = " << x << "\n";
    return 0;
}
long long a, b, c, d;
Keeps every multiplication safely inside 64-bit range.
a * b - c * d
* binds tighter than -, so this is (a*b) - (c*d) exactly as the statement defines X.
"Difference = "
Matches the required label exactly, including the trailing space before the number.

Homework

Three problems: your first if/else conditions.

An if statement runs a block of code only when a condition is true; else covers every other case:

if (a >= b) {
    cout << "Yes" << "\n";
} else {
    cout << "No" << "\n";
}

Comparison operators in C++: == (equal — note the double equals, since a single = means assignment), != (not equal), <, >, <=, >=. You can chain more conditions with else if.

A. Welcome for you with Conditions

Time limit: 1 second · Memory limit: 64 MB

Statement

Given two numbers A and B. Print "Yes" if A is greater than or equal to B. Otherwise print "No".

Input / Output

One line: A B with 0 ≤ A, B ≤ 100
InputOutput
10 9
Yes
5 5
Yes
5 7
No

How to think about it

This is the most direct possible use of an if/else: the condition in the statement (A greater than or equal to B) is literally the C++ expression a >= b. Note that "equal" counts as "greater than or equal", which the 5 5 → Yes example confirms.

Hints

Hint 1

Read a and b as ints, then write one if/else.

Hint 2

The condition is a >= b, not a > b — make sure equal values print "Yes".

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a >= b) cout << "Yes" << "\n";
    else cout << "No" << "\n";
    return 0;
}
if (a >= b) ... else ...
Directly mirrors the statement's condition; a single statement after if/else doesn't need braces, though adding them is also fine.

B. Comparison

Time limit: 1 second · Memory limit: 256 MB

Statement

Given a comparison symbol S between two numbers A and B. Determine whether it is Right or Wrong.

The comparison is as follows: A<B, A>B, A=B.

Where A, B are two integer numbers and S refers to the sign between them.

Input / Output

One line: A S B with −100 ≤ A, B ≤ 100, S is one of <, > or =.
InputOutput
5 > 4
Right
9 < 1
Wrong
4 = 4
Right

How to think about it

The input's middle token is a single character, so you can read it straight into a char with cin >> s — whitespace around it is skipped automatically, same as in "Basic Data Types". Once you have a, s, b, you check which symbol s is and evaluate the matching comparison.

Watch out for

Comparing a char to a character literal uses single quotes: s == '<', not double quotes. Double quotes ("<") make a string, which is a different type and won't compare equal to a char.

Hints

Hint 1

Read three variables in order: an int, a char, an int.

Hint 2

Use if (s == '<'), else if (s == '>'), else (must be '=') to figure out which comparison to perform.

Hint 3

Inside each branch, check the actual relationship between a and b (e.g. a < b for the '<' branch) and print "Right" if it holds, "Wrong" otherwise.

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    char s;
    cin >> a >> s >> b;

    bool right;
    if (s == '<') right = (a < b);
    else if (s == '>') right = (a > b);
    else right = (a == b);

    cout << (right ? "Right" : "Wrong") << "\n";
    return 0;
}
cin >> a >> s >> b;
Reads the number, the symbol, then the second number, in input order.
if (s == '<') ... else if (s == '>') ... else ...
Since s is guaranteed to be one of the three symbols, "otherwise" safely means '='.
right ? "Right" : "Wrong"
The ternary operator is a compact if/else that produces a value; equivalent to writing a full if/else around the cout line.

C. First digit !

Time limit: 0.25 seconds · Memory limit: 64 MB

Statement

Given a number X. Print "EVEN" if the first digit of X is an even number. Otherwise print "ODD".

For example: in 4569 the first digit is 4, the second digit is 5, the third digit is 6 and the fourth digit is 9.

Input / Output

One line: X with 999 < X ≤ 9999 (always exactly 4 digits)
InputOutput
4569
EVEN
3569
ODD

How to think about it

Because X is guaranteed to have exactly 4 digits (it's strictly above 999 and at most 9999), the first digit is always the thousands digit. You can peel it off with integer division: X / 1000 throws away everything after the thousands place. For 4569, 4569 / 1000 is 4 in integer (whole-number) division — C++ truncates, it doesn't round.

Once you have that single digit, checking even/odd is the same idea as "last digit" from problem B: a number is even exactly when digit % 2 == 0.

Hints

Hint 1

You don't need to look at the digits as characters or convert anything to a string — plain integer arithmetic gets you the first digit directly.

Hint 2

Divide by 1000 using integer division (/ on two ints truncates towards zero) to isolate the thousands digit.

Hint 3

Take that digit modulo 2. If the remainder is 0 it's even → print "EVEN", otherwise print "ODD".

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    int x;
    cin >> x;
    int firstDigit = x / 1000;
    if (firstDigit % 2 == 0) cout << "EVEN" << "\n";
    else cout << "ODD" << "\n";
    return 0;
}
x / 1000
Integer division drops the remainder, leaving just the thousands digit (e.g. 4569 / 1000 = 4).
firstDigit % 2 == 0
True exactly when the digit is even (0, 2, 4, 6 or 8).
