A

Basic Data Types

Data types

Every variable has a type. The ones you'll use most:

TypeStoresRange
intInteger, 32 bitsabout ±2.1×109
long longInteger, 64 bitsabout ±9.2×1018
charOne character'a', '7', '>'
floatReal number, 32 bitsabout 7 significant digits
doubleReal number, 64 bitsabout 15 significant digits

Pick the type from the constraints: if a value can exceed about 2×109, use long long. For real numbers, use double unless told otherwise.

Input with cin

Read with cin >>, chained like cout. Values are read in order, and spaces and newlines between them are skipped.

int n;
char c;
double x;
cin >> n >> c >> x;   // input: 42 z 2.5

By default, cout prints real numbers with 6 significant digits:

double a = 3.14159265, b = 14049.30493;
cout << a << " " << b << "\n";
Output 
3.14159 14049.3

That's usually fine, since problems with real-number output accept a small error. For a fixed number of decimals, use cout << fixed << setprecision(k) from <iomanip>.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int a;
    long long b;
    char c;
    float f;
    double d;
    cin >> a >> b >> c >> f >> d;
    cout << a << "\n" << b << "\n" << c << "\n" << f << "\n" << d << "\n";
    return 0;
}

Read each value into its matching type and print each one on its own line. b needs long long.

B

Digits Summation

Arithmetic

The operators are + - * / %. Two need attention:

  • / on two integers drops the fraction: 7 / 2 is 3. Use 7.0 / 2 to get 3.5.
  • % is the remainder: 7 % 2 is 1.

% and / by 10 are the standard way to work with digits:

int n = 4096;
cout << n % 10 << "\n";   // 6   (last digit)
cout << n / 10 << "\n";   // 409 (last digit removed)

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    long long n, m;
    cin >> n >> m;
    cout << n % 10 + m % 10 << "\n";
    return 0;
}

Add the last digits with % 10. N and M go up to 1018, so they need long long.

Difference

Integer overflow

If a result doesn't fit in its type, it overflows and silently becomes a wrong value. There is no error:

int x = 100000;
cout << x * x << "\n";         // prints 1410065408, not 10000000000

long long y = x * x;           // still wrong: x * x is computed as int

A calculation is done in the type of its operands, not the type you store it in. If a result can exceed about 2×109, declare the variables themselves as long long.

Operator precedence is the usual one: * / % before + -, left to right. Use parentheses when in doubt.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    long long a, b, c, d;
    cin >> a >> b >> c >> d;
    cout << "Difference = " << a * b - c * d << "\n";
    return 0;
}

Each product can reach 1010, so everything is long long. Print the label exactly as written, including the spaces.
