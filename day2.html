Day 2: Data types and arithmetic

This day introduces variables, the basic C++ data types, reading input with cin, and arithmetic. It closes with integer overflow, one of the most common causes of wrong answers in competitive programming.

Contents

  2. Reading input with cin

Lesson 1

Variables and data types

A variable is a named location in memory that stores a value. In C++, every variable has a data type, which determines what kind of value it can hold and how much memory it uses. A variable is created by writing its type followed by its name:

int age = 19;          // a whole number
char grade = 'A';      // a single character, in single quotes
double height = 1.78;  // a real number

age = 20;               // a variable's value can be changed later

The five types you will use most often are:

TypeStoresSizeRange or precision
intIntegers32 bits−2,147,483,648 to 2,147,483,647 (about ±2.1×109)
long longIntegers64 bitsAbout ±9.2×1018
charA single character8 bitsLetters, digits and symbols, e.g. 'a', '7', '>'
floatReal numbers32 bitsAbout 7 significant digits
doubleReal numbers64 bitsAbout 15 significant digits

Choosing a type is a matter of reading the problem's constraints. If a value can be as large as 1018, an int cannot hold it and a long long is required. For real numbers, prefer double over float unless a problem specifically asks for float, since double is considerably more precise.

Why C++

C++ is the language of choice in competitive programming, not simply the language this course happens to use. It is among the fastest languages available, gives precise control over data types and memory, and its standard library provides efficient implementations of the data structures and algorithms you will rely on in later days. The large majority of top ICPC teams compete in C++.

Lesson 2

Reading input with cin

Most problems provide input that your program must read. Input is read with cin ("character input") and the extraction operator >>, which takes the next value from the input and stores it in a variable. Like cout, it can be chained:

int n;
char c;
double x;
cin >> n >> c >> x;   // reads three values, in this order

cout << n << "\n";
cout << c << "\n";
cout << x << "\n";

With the input 42 z 2.5, this program prints 42, z and 2.5 on three separate lines. Note that printing a variable does not use quotes: cout << n prints the value stored in n, while cout << "n" prints the letter n.

cin skips any spaces and line breaks before each value, so it does not matter whether the values are on one line or several. When reading into a char, it skips whitespace and then reads exactly one character.

How real numbers are printed

By default, cout prints real numbers with at most 6 significant digits in total, not 6 digits after the decimal point. Trailing zeros are omitted.

double a = 2.50, b = 3.14159265, c = 14049.30493;
cout << a << " " << b << " " << c << "\n";
Output 
2.5 3.14159 14049.3

Problems that print real numbers usually accept a small error, stated in the output section (for example, an absolute or relative error of at most 10−5), so the default format is often sufficient. When more digits are needed, cout << fixed << setprecision(k) prints exactly k digits after the decimal point.

Practice problem

A. Basic Data Types

Solve this problem on Codeforces using lessons 1 and 2, then review the reference solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a;
    long long b;
    char c;
    float f;
    double d;
    cin >> a >> b >> c >> f >> d;

    cout << a << "\n";
    cout << b << "\n";
    cout << c << "\n";
    cout << f << "\n";
    cout << d << "\n";
    return 0;
}
long long b;
The second value can be as large as about 9.2×1018, which only a long long can hold.
cin >> a >> b >> c >> f >> d;
Reads the five values in the order they appear in the input.
cout << f / cout << d
The default 6-significant-digit format is within the problem's allowed error, so no special formatting is needed.
Lesson 3

Arithmetic operators

C++ provides the usual arithmetic operators. The result can be printed directly or stored in a variable.

OperatorOperationExampleResult
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division7 / 23
%Remainder (modulo)7 % 21

Integer division

When both operands are integers, / performs integer division: the fractional part is discarded, so 7 / 2 is 3, not 3.5. To obtain a real result, at least one operand must be a real number, as in 7.0 / 2, which gives 3.5.

The modulo operator

The % operator gives the remainder after integer division. Since 7 = 2 × 3 + 1, 7 % 2 is 1. Modulo is used constantly in competitive programming. Two common uses:

  • Divisibility: a % b == 0 exactly when a is divisible by b. For example, a number is even when n % 2 == 0.
  • Digits: for a non-negative integer, n % 10 is its last digit, and n / 10 removes its last digit.
int n = 4096;
cout << n % 10 << "\n";   // 6   (last digit)
cout << n / 10 << "\n";   // 409 (last digit removed)
cout << n % 2 << "\n";    // 0   (n is even)
Practice problem

B. Digits Summation

Solve this problem on Codeforces using lessons 1 to 3, then review the reference solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, m;
    cin >> n >> m;
    cout << n % 10 + m % 10 << "\n";
    return 0;
}
long long n, m;
Both numbers can be as large as 1018, which exceeds the range of int.
n % 10 + m % 10
Takes the last digit of each number and adds them. % is evaluated before +, so no parentheses are needed.
Lesson 4

Integer overflow

Each integer type can only represent values within its range. When the result of a calculation falls outside that range, it overflows: the program does not stop or report an error, it silently produces an incorrect value.

int x = 100000;
cout << x * x << "\n";   // expected 10000000000
Output 
1410065408

The true result, 1010, is larger than the maximum int value of about 2.1×109. The type of a calculation is decided by its operands, not by where the result is stored, so the following is still wrong:

int x = 100000;
long long y = x * x;   // still overflows: x * x is computed as int

The reliable approach is to declare the variables themselves as long long whenever a calculation involving them could exceed about 2×109. To decide, estimate the largest possible result using the problem's constraints before writing any code.

Order of operations

C++ follows the usual mathematical order: *, / and % are evaluated before + and -, and operators of equal priority are evaluated from left to right. Parentheses can always be used to make the order explicit.

cout << 2 + 3 * 4 << "\n";     // 14
cout << (2 + 3) * 4 << "\n";   // 20

Printing text and values together

String literals and variables can be combined in a single cout statement. Remember that spaces are only printed where you write them:

int total = 42;
cout << "Total = " << total << "\n";   // Total = 42
Practice problem

C. Difference

Solve this problem on Codeforces using lessons 1 to 4, then review the reference solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long a, b, c, d;
    cin >> a >> b >> c >> d;
    long long x = a * b - c * d;
    cout << "Difference = " << x << "\n";
    return 0;
}
long long a, b, c, d;
Each value can be up to 105 in absolute value, so a product can reach 1010. Declaring the variables as long long ensures the multiplications are carried out in 64 bits.
a * b - c * d
Both multiplications are evaluated before the subtraction, matching (A × B) − (C × D).
"Difference = "
The label is printed exactly as required, including the space after the equals sign.
