Basic Data Types

Data types

Every variable has a type that decides what it can store. These are the most common ones:

TypeStoresRange
intInteger, 32 bitsabout ±2.1×109
long longInteger, 64 bitsabout ±9.2×1018
charOne character'a', '7', '>'
floatReal number, 32 bitsabout 7 significant digits
doubleReal number, 64 bitsabout 15 significant digits

Choose the type based on the constraints. An int goes up to about 2×109, so anything larger needs a long long. For decimal numbers, use double, since float is less precise.

Input with cin

cin reads values from the input into your variables, in the order you list them.

int n;
char c;
double x;
cin >> n >> c >> x;   // input: 42 z 2.5

The values can be on one line or several; cin skips the spaces and newlines between them.

By default, cout prints decimal numbers with 6 significant digits, so longer numbers get rounded:

double a = 3.14159265, b = 14049.30493;
cout << a << " " << b << "\n";
Output 
3.14159 14049.3

This is usually fine, since problems with decimal output accept a small error.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int a;
    long long b;
    char c;
    float f;
    double d;
    cin >> a >> b >> c >> f >> d;
    cout << a << "\n" << b << "\n" << c << "\n" << f << "\n" << d << "\n";
    return 0;
}

Read each value into the matching type and print them on separate lines. b is too large for an int, so it needs long long.

B

Digits Summation

Arithmetic

The arithmetic operators are + - * / %. Two of them need some care:

  • Dividing two integers with / drops the decimal part, so 7 / 2 is 3. To get 3.5, make one of them a decimal: 7.0 / 2.
  • % gives the remainder, so 7 % 2 is 1.

% 10 gives the last digit of a number, and / 10 removes it:

int n = 4096;
cout << n % 10 << "\n";   // 6   (last digit)
cout << n / 10 << "\n";   // 409 (last digit removed)

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    long long n, m;
    cin >> n >> m;
    cout << n % 10 + m % 10 << "\n";
    return 0;
}

Take the last digit of each number with % 10 and add them. N and M can be up to 1018, so they need long long.

Difference

Integer overflow

Every type has a maximum value. If a result goes past it, it overflows and wraps around to a wrong value, without any error or warning.

int x = 100000;
cout << x * x << "\n";         // prints 1410065408, not 10000000000

long long y = x * x;           // still wrong: x * x is computed as int

The second line is also wrong. Since x is an int, the multiplication is done as an int before the result is stored in y, so it overflows anyway. To avoid this, declare the variables themselves as long long.

* / % are evaluated before + -, as in math. Use parentheses if you're unsure.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    long long a, b, c, d;
    cin >> a >> b >> c >> d;
    cout << "Difference = " << a * b - c * d << "\n";
    return 0;
}

A × B can reach 1010, which doesn't fit in an int, so use long long. Print Difference = exactly as written, including the spaces.
