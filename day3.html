A

Summation from 1 to N

The sum formula

The sum of all numbers from 1 to N has a closed formula:

sum = n * (n + 1) / 2;

Adding the numbers one by one would take up to 109 additions, which is far too slow for a 0.25 second time limit. The formula gives the answer in a single step.

n * (n + 1) is always even, so dividing by 2 afterwards is exact.

Watch the size of the result

With N up to 109, n * (n + 1) is about 1018. That fits in a long long but not in an int, so n itself should be a long long (see overflow on Day 2).

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    cout << n * (n + 1) / 2 << "\n";
    return 0;
}

Apply the formula directly. n is a long long so the multiplication doesn't overflow.

B

Mathematical Expression

Conditions with if

if runs a block of code only when its condition is true. else if checks another condition, and else handles everything left over:

if (x > 0) {
    cout << "positive" << "\n";
} else if (x < 0) {
    cout << "negative" << "\n";
} else {
    cout << "zero" << "\n";
}

The comparison operators are ==, !=, <, >, <= and >=. Note that equality is ==; a single = is assignment.

Reading and comparing characters

Symbols like + and = in the input can be read into a char, just like numbers are read into an int. Since cin skips spaces, the input 5 + 10 = 15 can be read with:

int a, b, c;
char s, q;
cin >> a >> s >> b >> q >> c;

To check which symbol you read, compare it with a character in single quotes, for example s == '+'. Double quotes ("+") make a string, which is a different type.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    char s, q;
    cin >> a >> s >> b >> q >> c;

    int result;
    if (s == '+') result = a + b;
    else if (s == '-') result = a - b;
    else result = a * b;

    if (result == c) cout << "Yes" << "\n";
    else cout << result << "\n";
    return 0;
}

Compute the correct result based on the sign, then compare it with c. The = sign is read into q and not used.

C

The Middel Digit

Digits and place value

Each digit of a number is worth a different amount depending on its position. In a three-digit number, the first digit counts hundreds, the second counts tens and the third counts ones:

365 = 3 * 100 + 6 * 10 + 5

So changing the tens digit by some amount changes the whole number by ten times that amount. Subtracting 2 from the tens digit of 365 gives 345, which is the same as 365 - 20.

There's no need to split the number into digits here. The statement guarantees the second digit is at least 2, so it never goes negative.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    cout << x - 20 - y << "\n";
    return 0;
}

Subtracting 2 from the tens digit of X is the same as subtracting 20 from X. The answer can be negative, which is fine.

D

Age in Days

Converting units with / and %

To split a quantity into bigger units, divide to get how many whole units fit, and take the remainder to get what's left. For example, converting seconds into minutes and seconds:

int total = 150;
int minutes = total / 60;   // 2
int seconds = total % 60;   // 30

With more than two units, repeat the same idea on the remainder. First take out the largest unit, then split what's left into the next one, and so on.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int years = n / 365;
    n %= 365;
    int months = n / 30;
    int days = n % 30;
    cout << years << " years\n";
    cout << months << " months\n";
    cout << days << " days\n";
    return 0;
}

Take out the years first, then split the remaining days into months and days. n %= 365 is short for n = n % 365.

E

Max and Min

min and max

The <algorithm> header provides min(a, b) and max(a, b), which return the smaller and the larger of two values:

cout << min(4, 9) << "\n";   // 4
cout << max(4, 9) << "\n";   // 9

They only take two values at a time. For three values, nest them: min(a, min(b, c)).

Remember to add #include <algorithm> at the top of your program, since <iostream> alone doesn't provide these.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    cout << min(a, min(b, c)) << " " << max(a, max(b, c)) << "\n";
    return 0;
}

Nest min and max to handle three values, and print them separated by a single space.
