Summation from 1 to N

The time limit

This is the first problem where the time limit actually matters. The basic solution is to loop over every number from 1 to n and add them up, but n can be as large as 109, so that means up to 109 operations.

As a rule of thumb, a solution that does fewer than about 107 operations is fast enough to get Accepted, and one that does more than 108 will never pass. 109 is far over that, so we need a faster way to calculate the sum.

The sum formula

Luckily, one of the most useful formulas in competitive programming does exactly this:

1 + 2 + 3 + … + n = n (n + 1)2

Here's a visual proof. Stack the numbers 1 to n as a staircase of squares (red). Take a second copy of the same staircase (gold), flip it, and fit it against the first one:

With the formula, the answer takes a single calculation no matter how big n is.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    cout << n * (n + 1) / 2 << "\n";
    return 0;
}

Apply the formula directly. n (n + 1) can reach about 1018, so n needs to be a long long.

B

Mathematical Expression

Reading and comparing characters

Symbols like + and = in the input can be read into a char, just like numbers are read into an int. Since cin skips spaces, the input 5 + 10 = 15 can be read with:

int a, b, c;
char s, q;
cin >> a >> s >> b >> q >> c;

To check which symbol you read, compare it with a character in single quotes, for example s == '+'. Double quotes ("+") make a string, which is a different type.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    char s, q;
    cin >> a >> s >> b >> q >> c;

    int result;
    if (s == '+') result = a + b;
    else if (s == '-') result = a - b;
    else result = a * b;

    if (result == c) cout << "Yes" << "\n";
    else cout << result << "\n";
    return 0;
}

Compute the correct result based on the sign, then compare it with c. The = sign is read into q and not used.

C

The Middle Digit

Changing a digit

The second digit of a three-digit number is the tens digit, so reducing it by 2 is the same as subtracting 20 from the whole number.

The statement guarantees the second digit is at least 2, so it never goes negative after subtracting.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    cout << x - 20 - y << "\n";
    return 0;
}

Subtracting 2 from the tens digit of X is the same as subtracting 20 from X. The answer can be negative, which is fine.

D

Age in Days

Converting units with / and %

To split a quantity into bigger units, divide to get how many whole units fit, and take the remainder to get what's left. For example, converting seconds into minutes and seconds:

int total = 150;
int minutes = total / 60;   // 2
int seconds = total % 60;   // 30

With more than two units, repeat the same idea on the remainder. First take out the largest unit, then split what's left into the next one, and so on.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int years = n / 365;
    n %= 365;
    int months = n / 30;
    int days = n % 30;
    cout << years << " years\n";
    cout << months << " months\n";
    cout << days << " days\n";
    return 0;
}

Take out the years first, then split the remaining days into months and days. n %= 365 is short for n = n % 365.

E

Max and Min

min and max

min and max return the smallest and largest of the values you give them. They take either two numbers, or a whole list of numbers written inside curly braces:

cout << min(4, 9) << "\n";          // 4
cout << max({4, 9, 2, 7}) << "\n";   // 9

To use them, you need to include the <algorithm> library at the top of your program.

Including everything at once

Instead of including each library separately, you can write a single line that includes the entire standard library:

#include <bits/stdc++.h>

This doesn't make your program any slower. Including more libraries only adds to the compile time, and compile time isn't counted in the time limit.

From now on, we'll use <bits/stdc++.h> in all solutions. It works with the GCC compiler. If it doesn't work for you, you're using a different compiler, which is fine; just include each library you need at the top of your code instead.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    cout << min({a, b, c}) << " " << max({a, b, c}) << "\n";
    return 0;
}

Pass all three numbers to min and max in curly braces, and print the results separated by a single space.
