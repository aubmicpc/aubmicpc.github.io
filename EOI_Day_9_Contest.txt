A. Operations
time limit per test2 seconds
memory limit per test256 megabytes
Given 2 numbers a and b, we need to determine which operation we should apply in order to maximize the value. The operations are addition(+), subtraction(-), and multiplication(*). That means we may use (a + b) or (a - b) or (a * b).

Can you determine which operation should be used?

If multiple operations lead to same maximum value print the higher in priority. Assume multiplication(*) has highest priority then addition(+) then subtraction(-).

Input
The first line will contain (1 <  = T <  = 105) the number of test cases. Each test case will be on a separate line containing two integers a and b.

Output
For each test case, print the operation that maximizes the value.

Scoring
Sub task #1 (30 points): (0 < T <  = 100000) ( - 1000 <  = a, b <  = 1000).

Sub task #2 (30 points): (0 < T <  = 100000) ( - 109 <  = a, b <  = 109).

Sub task #3 (40 points): (0 < T <  = 100000) ( - 1018 <  = a, b <  = 1018).

Example
InputCopy
3
2 3
-4 5
3 -7
OutputCopy
*
+
-

D. Most Repeated Divisor
time limit per test1 second
memory limit per test256 megabytes

 and R

 to R
 inclusive, we wrote down all of their integer divisors except 1

Find the divisor that we wrote down the maximum number of times.

NOTE: If there are more than one correct solution print the minimum number.

Input
Only one line containing two integers L
 and R
.

Output
Output one number, the most repeated divisor.

Scoring
You get the points of the subtask if you passed all cases in this subtask and also all subtasks that this subtask depends on.

Subtask #1 (15 points):

2≤L=R≤100
Depends on: none

2≤L≤R≤103
Depends on: Subtask #1

Depends on: Subtask #1 and Subtask #2
Subtask #4 (53 points):

2≤L≤R≤1012
Depends on: Subtask #1, Subtask #2 and Subtask #3

OutputCopy
2
Note
