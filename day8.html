A

Binary Search

Why searching the array is too slow

On Day 6 you searched an array by checking every element. Doing that for each query takes up to N × Q = 105 × 105 = 1010 operations, which is far too slow. We need a much faster way to answer each query.

Sorting

sort puts the elements of an array in increasing order:

vector<int> a = {1, 5, 4, 3, 2};
sort(a.begin(), a.end());
// a is now {1, 2, 3, 4, 5}

a.begin() and a.end() tell sort to sort the whole array. Sorting N elements takes about N × log2 N operations, which for N = 105 is under 2 × 106.

Binary search

Once the array is sorted, you don't need to check every element. Look at the middle element of the part you're searching:

  • If it equals X, you've found it.
  • If it's smaller than X, X can only be to its right, so throw away the left half.
  • If it's bigger than X, X can only be to its left, so throw away the right half.

Keep the part you're still searching between two indexes, lo and hi. Each step cuts it in half, and when lo passes hi there's nothing left, so X isn't in the array:

int lo = 0, hi = n - 1;
bool found = false;
while (lo <= hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] == x) {
        found = true;
        break;
    }
    else if (a[mid] < x) lo = mid + 1;
    else hi = mid - 1;
}

Here's how it runs for X = 6 in the sorted sample array {1, 2, 3, 4, 5}:

lohimida[mid]Next
04233 < 6, so lo = 3
34344 < 6, so lo = 4
44455 < 6, so lo = 5
54lo > hi, not found

Because the search space halves every step, an array of 105 elements needs at most about 17 steps. All Q queries together take around 1.7 × 106 operations.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a.begin(), a.end());

    while (q--) {
        int x;
        cin >> x;
        int lo = 0, hi = n - 1;
        bool found = false;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (a[mid] == x) {
                found = true;
                break;
            }
            else if (a[mid] < x) lo = mid + 1;
            else hi = mid - 1;
        }
        if (found) cout << "found" << "\n";
        else cout << "not found" << "\n";
    }
    return 0;
}

Sort the array once, then answer each query with a binary search.

Reading words

Each query starts with a word saying its type. A word is read into a string, and it can be compared with text in double quotes:

string type;
int x;
cin >> type >> x;
if (type == "lower_bound") {
    // ...
}

The built-in binary searches

C++ has binary search built in, as part of the Standard Template Library (STL). All three functions below only work on a sorted array, so sort it first.

binary_search returns true if X is in the array and false otherwise, which is exactly what you wrote by hand in problem A:

if (binary_search(a.begin(), a.end(), x)) cout << "found" << "\n";

lower_bound finds the first element that is greater than or equal to X, and upper_bound finds the first element that is strictly greater than X. Subtracting a.begin() turns the result into an index:

int i = lower_bound(a.begin(), a.end(), x) - a.begin();

If no such element exists, the index is n, one past the last element. In that case print -1; otherwise the answer is a[i].

For example, in the sorted array {1, 2, 3, 4, 5}, lower_bound of 3 gives index 2 (the 3 itself) and upper_bound of 3 gives index 3 (the 4). upper_bound of 5 gives index 5, which is n, so the answer is -1.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a.begin(), a.end());

    while (q--) {
        string type;
        int x;
        cin >> type >> x;
        if (type == "binary_search") {
            if (binary_search(a.begin(), a.end(), x)) cout << "found" << "\n";
            else cout << "not found" << "\n";
        }
        else {
            int i;
            if (type == "lower_bound") i = lower_bound(a.begin(), a.end(), x) - a.begin();
            else i = upper_bound(a.begin(), a.end(), x) - a.begin();

            if (i == n) cout << -1 << "\n";
            else cout << a[i] << "\n";
        }
    }
    return 0;
}

Sort the array, read each query's type, and call the matching built-in function. For lower_bound and upper_bound, an index of n means there is no such element.
