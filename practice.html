Practice Sheet

The practice sheet is the official training material for AUBM's ICPC candidates during the 2026 practice period. It introduces the C++ language and the fundamentals of competitive programming one day at a time, in preparation for the selection contest.

About the programme

Each day is organised around a small number of programming concepts. Every concept is explained from first principles, illustrated with worked examples in C++, and then applied to a practice problem from the AUBM ICPC group on Codeforces. A reference solution is provided for each practice problem.

Prior programming experience is not assumed. All material is written in C++, the language used throughout the course and the one recommended for the contest.

  • 1. Study the concept

    Read each lesson carefully and make sure you understand the examples before moving on.

  • 2. Solve the problem

    Write your own solution to the practice problem and submit it on Codeforces.

  • 3. Review the solution

    Once you have attempted the problem, compare your approach with the reference solution.
