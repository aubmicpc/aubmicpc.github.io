ICPC at AUBM / Practice

Practice, day by day

Each day pairs a short practice set with homework. Every problem here walks you through the real Codeforces statement, teaches the C++ you need to solve it, gives hints if you get stuck, and has a full worked solution you can reveal when you're ready. Solve the problem yourself first, then submit it on the group's Codeforces page.

How to use this

Work through the days in order. For each problem: read the statement, try to write the code yourself, and only open a hint if you're stuck for more than a few minutes. Hints are ordered from a small nudge to a near-complete plan, so open them one at a time. The full solution is hidden by default — use it to check your work or to see a clean approach after you've submitted your own.
