Day 1: your first C++ program

Two problems, both about the same skill: getting a C++ program to compile and print exactly the text that's asked for. This is the foundation everything else builds on.

  • Practice A · Hello AUBM
  • Homework A · Motivation

Before you start

Every C++ program that reads input or produces output on Codeforces has the same skeleton:

// 1. bring in the standard library tools (cin, cout, etc.)
#include <bits/stdc++.h>
using namespace std;

// 2. every C++ program starts running at main()
int main() {
    // 3. your code goes here

    return 0; // 4. tell the OS the program finished successfully
}

#include <bits/stdc++.h> pulls in the whole standard library in one line — it's not "real" standard C++ (it's a GCC extension), but it's what almost everyone uses in competitive programming because it saves you from remembering which header has which tool. using namespace std; means you can write cout instead of std::cout.

To print text, use cout (character output) with the << operator, which you can chain:

cout << "Hello" << " " << "World" << "\n";

A few things that trip people up the first time:

  • Text you want printed literally must be inside double quotes "...".
  • Every statement ends with a semicolon ;.
  • "\n" inside a string means "start a new line" — it's not two characters, it's one newline character written with two symbols.
  • Codeforces checks your output character for character against the expected answer (ignoring trailing whitespace/newlines). Capitalization, spelling and punctuation all have to match exactly.
  • To submit: open the problem on Codeforces, paste your code into the submit box, choose language GNU G++17 (or any recent GNU C++), and submit.

Practice

One problem: get comfortable with the skeleton above and with printing exact text.

A. Hello AUBM

Time limit: 2 seconds · Memory limit: 256 MB

Statement

Hello, Smarty.

Print "Hello AUBM" without quotes.

Input / Output

This problem has no input.

Output
Hello AUBM

How to think about it

There's no input to read at all, so your entire program is: set up the skeleton, then print one line of text. This is really a test of whether you can write, compile and submit a C++ program — the "logic" is a single cout statement.

Watch out for

The exact spelling and capitalization: Hello AUBM, with a single space, capital H, and AUBM in all caps. hello aubm or Hello, AUBM would both be judged wrong.

Hints

Hint 1

You don't need to read anything with cin. You only need one line inside main().

Hint 2

Use cout << "..." with the exact text between the quotes, matching the required output exactly.

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello AUBM" << "\n";
    return 0;
}
cout << "Hello AUBM"
Sends the literal text Hello AUBM to standard output.
<< "\n"
Adds a trailing newline. Codeforces doesn't require it, but it's good habit for every line you print.

Homework

Same skill, reinforced with a longer, trickier string to copy exactly.

A. Motivation

Time limit: 1 second · Memory limit: 256 MB

Statement

Every champion starts with the right mindset.

Print "I will win the ICPC because I am a great programmer" without quotes.

Input / Output

This problem has no input.

Output
I will win the ICPC because I am a great programmer

How to think about it

Identical idea to the practice problem, just a longer sentence. The only new risk is a typo somewhere in the middle of a long string — the judge won't tell you where it's wrong, just that your output doesn't match.

Watch out for

Getting ICPC in all caps, single spaces between every word, and no extra punctuation. It helps to type the sentence once, then re-read it character by character against the statement before you submit.

Hints

Hint 1

Same structure as Hello AUBM: one cout statement inside main().

Hint 2

Copy the sentence straight from the statement into your quotes so you don't introduce a typo by retyping it from memory.

Solution

#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "I will win the ICPC because I am a great programmer" << "\n";
    return 0;
}
cout << "I will win..."
One string, printed exactly as given in the statement.
