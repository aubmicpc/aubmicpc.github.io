Day 1: Your first C++ program

This day covers the minimum needed to write, run and submit a working C++ program: how a program is structured, how to print text, and how Codeforces judges a submission.

Contents

  2. Printing output with cout

Lesson 1

The structure of a C++ program

A C++ program is a text file containing instructions that a compiler translates into a program the computer can run. Every program you write in this course starts from the same skeleton:

#include <bits/stdc++.h>
using namespace std;

int main() {
    // your instructions go here
    return 0;
}

Each line has a specific purpose:

  • #include <bits/stdc++.h> gives your program access to the C++ standard library, which contains ready-made tools for input, output, mathematics and more. This single header includes all of them, which is why it is standard practice in competitive programming.
  • using namespace std; lets you write names from the standard library directly, such as cout, instead of the full form std::cout.
  • int main() { ... } defines the main function. When the program runs, execution begins at the first line inside its braces and proceeds line by line, top to bottom.
  • return 0; ends the program and reports to the operating system that it finished successfully.

Lines beginning with // are comments. The compiler ignores them; they exist only to explain the code to a human reader.

Syntax rules

C++ is case-sensitive: Main and main are different names. Every instruction ends with a semicolon ;, and every opening brace { must have a matching closing brace }. A missing semicolon is the most common reason a beginner's program fails to compile.

Lesson 2

Printing output with cout

To display text, use cout (short for "character output") followed by the insertion operator << and the value to print. Text is written inside double quotes; a piece of quoted text is called a string literal.

cout << "Welcome to AUBM";

Several values can be printed in one statement by chaining <<. They are printed one after another, with nothing added in between, so any spaces you want must be written explicitly:

cout << "ICPC" << " " << "Cyprus" << "\n";
cout << "2026" << "\n";
Output 
ICPC Cyprus
2026

The sequence "\n" is the newline character. Printing it moves the output to the start of the next line. Without it, consecutive cout statements continue on the same line. You may also see endl used for the same purpose; it behaves identically for our needs but is slower, so "\n" is preferred.

Exactness

A program's output is compared with the expected answer character by character. Spelling, capitalization, spaces and punctuation must all match exactly: Hello World, hello world and Hello, World are three different outputs.

Lesson 3

How Codeforces judges your program

Problems in this course are hosted on Codeforces. To submit a solution, open the problem, select a C++ compiler (any recent GNU G++ version, such as GNU G++17 or G++20), paste your code, and submit. Your program is then run automatically against a set of hidden tests, and you receive a verdict:

VerdictMeaning
AcceptedYour program produced the correct output for every test.
Wrong answerOn at least one test the output differed from the expected answer.
Compilation errorThe code is not valid C++, for example because of a missing semicolon or a misspelled name.
Time limit exceededThe program took longer than the problem's time limit.
Runtime errorThe program crashed while running.

Before submitting, compile and run your program on your own computer and check that its output matches the examples in the problem statement.

Practice problem

A. Hello AUBM

Solve this problem on Codeforces using the three lessons above, then review the reference solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello AUBM" << "\n";
    return 0;
}
cout << "Hello AUBM"
The problem has no input, so the program only prints the required text, spelled and capitalized exactly as in the statement.
<< "\n"
Ends the line. It is not strictly required here, but ending every line of output this way is good practice.
