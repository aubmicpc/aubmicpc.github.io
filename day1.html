Setting up C++

Before you start, set up C++ on your laptop in your favorite code editor. You need two things:

  • A compiler, which turns your C++ code into a program the computer can run. We recommend GCC (g++), the same compiler Codeforces uses.
  • A code editor to write your code in. We recommend Visual Studio Code (VS Code), a free editor available on Windows, macOS and Linux.

The exact steps depend on your operating system, so use an AI assistant to guide you through the installation. You can ask it something like:

I want to write C++ for competitive programming on my laptop, which runs [Windows / macOS / Linux]. Walk me through installing the g++ compiler and setting up VS Code step by step, so that I can compile and run a program that uses #include <bits/stdc++.h>.

If something goes wrong along the way, copy the exact error message into the same conversation and ask what it means.

Check that it works

Once everything is installed, create a file called main.cpp, paste in this program, then compile and run it. You don't need to understand it yet; problem A below explains every line.

#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "It works!" << "\n";
    return 0;
}

If it prints It works!, your setup is complete.

Getting started on Codeforces

Codeforces is one of the largest competitive programming websites. It hosts contests almost every week and has thousands of problems to practice on. All of our practice and homework problems are hosted on Codeforces, in the AUBM ICPC group.

Creating an account

  1. Go to codeforces.com and click Register in the top-right corner.
  2. Choose a handle, enter your email address and a password, and submit the form.
  3. Open the confirmation email Codeforces sends you and click the link to activate your account.

Joining the AUBM group

  1. Log in to Codeforces.
  2. Open the AUBM ICPC group link that was shared with you and click Join. If the group requires approval, your request will be accepted by the organizers.
  3. Once you are a member, the group page lists its contests. Each day of the practice sheet has two: Day N Practice and Day N Homework.

Open a contest to see its problems, which are labeled with letters (A, B, C, ...).

Reading a problem

Every problem statement follows the same structure:

PartWhat it tells you
Time limitThe maximum time your program may run on a single test, for example 1 second.
Memory limitThe maximum memory your program may use, for example 256 megabytes.
StatementThe task your program has to solve.
InputExactly what your program will be given, in what order, and the constraints: the smallest and largest possible values.
OutputExactly what your program must print, and in what format.
ExamplesSample inputs with their correct outputs. Test your program on every one before submitting.

Read the input and output sections as carefully as the statement itself. Most early mistakes come from reading the input in the wrong order or printing in the wrong format.

Submitting a solution

  1. Make sure your program compiles and produces the correct output for every example on your own computer.
  2. On the problem page, find the Submit box on the right, or open the Submit Code tab at the top of the contest.
  3. Select a language. Choose the newest GNU G++ option available, such as GNU G++20 or GNU G++17.
  4. Paste your code, or choose your .cpp file, and click Submit.

You are taken to the My Submissions page. Your program is run on a set of hidden tests, one after another, and after a few seconds you receive a verdict:

VerdictMeaning
AcceptedYour program passed every test. The problem is solved.
Wrong answer on test NYour output on test N differed from the expected output. "On test 1" usually means the first example from the statement fails.
Compilation errorYour code is not valid C++. Click the verdict to see the compiler's error message.
Time limit exceeded on test NYour program ran longer than the time limit on test N.
Memory limit exceeded on test NYour program used more memory than allowed on test N.
Runtime error on test NYour program crashed on test N, for example by dividing by zero.

Important things to know

  • Print only what is asked. The judge is a program, not a person. Messages such as Enter a number: or The answer is: make your output wrong.
  • Output must match exactly. Spelling, capital letters, spaces and line breaks all count. Extra spaces or a blank line at the very end are usually ignored, but nothing else is.
  • Use standard input and output. Read with cin and print with cout. Do not open files, and do not use system("pause") or getch() to keep a window open.
  • Passing the examples is not enough. The hidden tests include large values and edge cases. Always check your program against the constraints in the input section.
  • Try before looking. When you are stuck, think about the problem a little longer before reading the solution. Struggling with a problem is how you improve.
A

Hello AUBM

The structure of a C++ program

A C++ program is a text file containing instructions that the compiler translates into a program the computer can run. Every program you write in this course starts from the same skeleton:

#include <bits/stdc++.h>
using namespace std;

int main() {
    // your instructions go here
    return 0;
}

Each line has a specific purpose:

  • #include <bits/stdc++.h> gives your program access to the C++ standard library, which contains ready-made tools for input, output, mathematics and more. This single line includes all of them, which is why it is standard practice in competitive programming.
  • using namespace std; lets you write names from the standard library directly, such as cout, instead of the full form std::cout.
  • int main() { ... } defines the main function. When the program runs, execution begins at the first line inside its braces and proceeds line by line, top to bottom.
  • return 0; ends the program and reports that it finished successfully.

Lines beginning with // are comments. The compiler ignores them; they exist only to explain the code to a human reader.

Syntax rules

C++ is case-sensitive: Main and main are different names. Every instruction ends with a semicolon ;, and every opening brace { must have a matching closing brace }. A missing semicolon is the most common reason a beginner's program fails to compile.

Printing output with cout

To print text, use cout (short for "character output") followed by the insertion operator << and the value to print. Text is written inside double quotes; a piece of quoted text is called a string literal.

cout << "Welcome to AUBM";

Several values can be printed in one statement by chaining <<. They are printed one after another with nothing added in between, so any spaces you want must be written explicitly:

cout << "ICPC" << " " << "Cyprus" << "\n";
cout << "2026" << "\n";
Output 
ICPC Cyprus
2026

The sequence "\n" is the newline character. Printing it moves the output to the start of the next line. Without it, consecutive cout statements continue on the same line. You may also see endl used for the same purpose; it works the same way for our needs but is slower, so "\n" is preferred.

Exactness

Your output is compared with the expected answer character by character. Hello World, hello world and Hello, World are three different outputs, and only one of them is correct.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello AUBM" << "\n";
    return 0;
}
cout << "Hello AUBM"
The problem has no input, so the program only prints the required text, spelled and capitalized exactly as in the statement.
<< "\n"
Ends the line. It is not strictly required here, but ending every line of output this way is good practice.
