Setting up C++

Set up C++ on your laptop in your favorite editor. We recommend VS Code with the GCC compiler (g++), which is what Codeforces uses. If you get stuck, ask an AI to walk you through the setup for your OS.

To test your setup, compile and run this. It should print It works!.

#include <iostream>
using namespace std;

int main() {
    cout << "It works!" << "\n";
    return 0;
}

Getting started on Codeforces

Account and group

  1. Register at codeforces.com and confirm your email.
  2. Open the AUBM ICPC group link shared with you and click Join.
  3. The group has two contests per day: Day N Practice and Day N Homework.

Reading a problem

  • Time and memory limits: per test, usually 1–2 seconds and 256 MB.
  • Input: what you are given, in what order, and the constraints (the range of every value). Constraints decide which data types you need and how fast your solution has to be.
  • Output: exactly what to print, and in what format.
  • Examples: sample tests. Your solution must pass these before you submit.

Submitting

On the problem page, use the Submit box on the right. Pick the newest GNU G++ compiler (G++20 or G++17), paste your code and submit. Your code is run on hidden tests and you get a verdict:

VerdictMeaning
AcceptedPassed every test.
Wrong answer on test NWrong output on test N. Test 1 is usually the first example.
Compilation errorCode doesn't compile. Click the verdict to see the error.
Time limit exceededToo slow.
Memory limit exceededUsed too much memory.
Runtime errorCrashed, e.g. division by zero or reading outside an array.

Hello AUBM

Program template

Every solution starts from this template:

#include <iostream>   // cin and cout
using namespace std; // lets you write cout instead of std::cout

int main() {
    // your code
    return 0;
}

Output with cout

Print with cout <<. You can chain values; nothing is added between them, so write spaces and newlines yourself.

cout << "ICPC" << " " << "Cyprus" << "\n";
cout << "2026" << "\n";
Output 
ICPC Cyprus
2026

Use "\n" for new lines rather than endl. endl also flushes the output, which makes it slow when you print a lot.

Solution

Try the problem on Codeforces before revealing the solution.

#include <iostream>
using namespace std;

int main() {
    cout << "Hello AUBM" << "\n";
    return 0;
}

No input, just print the exact string.
