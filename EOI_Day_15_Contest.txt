A. Clock
time limit per test1 second
memory limit per test256 megabytes
Dr. Evil bought a new clock. It's very beautiful but it has a small problem. It shows the time in 24-hour format and Dr. Evil is used to 12-hour format. Can you write a program that converts the time from 24-hour to 12-hour format?

In 24-hour format hours from 0 to 11 corresponds to hours from 0 to 11 AM and hours from 12 to 23 corresponds to hours from 0 to 11 PM.

Input
The only line of the input will contain two integers h
 and m
 which are the hour and the minute shown by the clock.

Output
Print one line containing two integers which are the hour and minute in 12-hour format then AM or PM.

Scoring
This problem is divided into subtasks you get the score of the subtask if you solved all cases in this subtask.

Subtask #1 (30 points):

0≤h≤11
 , 0≤m≤59
Subtask #2 (30 points):

12≤h≤23
 , 0≤m≤59
Subtask #3 (40 points):

0≤h≤23
 , 0≤m≤59
Examples

4 30
OutputCopy
4 30 AM
InputCopy
14 20
OutputCopy
2 20 PM
InputCopy
11 55
OutputCopy
11 55 AM
InputCopy
12 4
OutputCopy
0 4 PM

Problem C. Build the array
Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 256 megabytes
Dr. Evil likes special arrays. Today he wants an array with n elements and the summation of all elements
in it is exactly s. Also, the numbers in the array must be non-negative and not more than 109
. Can you
build an array that satisfies these conditions or state that it’s impossible?
Input
The only line of the input will contain two space-separated integers n and s.
Output
If there is no solution print a single line containing “NO” (without quotes) otherwise print “YES” (without
quotes) then a line containing any array satisfying the conditions.
Scoring
This problem is divided into subtasks you get the score of the subtask if you solved all cases in this
subtask.
Subtask #1 (10 points):
• N = 1
• 0 ≤ s ≤ 1018
Subtask #2 (15 points):
• N = 2
• 0 ≤ s ≤ 1018
Subtask #3 (20 points):
• 1 ≤ N ≤ 1000
• 0 ≤ s ≤ 109
Subtask #4 (35 points):
• 1 ≤ N ≤ 1000
• 0 ≤ s ≤ 1012
Subtask #5 (20 points):
• 1 ≤ N ≤ 1000
• 0 ≤ s ≤ 1018
