A

Summation

Arrays

An array stores many values of the same type under one name. In C++, the easiest way to make one is a vector:

vector<int> a(n);   // n ints, all starting at 0

Each value in the array is called an element, and you reach it by its position, called its index: a[0] is the first element, a[1] the second, and a[n - 1] the last. Indexes start at 0, not 1.

To read N numbers into the array, loop over every index:

for (int i = 0; i < n; i++) {
    cin >> a[i];
}

The loop goes from 0 to n - 1, which is why the condition is i < n.

Absolute value

abs(x) returns x without its minus sign: abs(-5) is 5 and abs(7) is 7.

Here the sum can reach 105 × 109 = 1014, so it needs to be a long long.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    long long sum = 0;
    for (int i = 0; i < n; i++) {
        sum += a[i];
    }
    cout << abs(sum) << "\n";
    return 0;
}

Read the array, add up its elements in a long long, and print the absolute value of the sum.

B

Searching

Searching an array

To find X, check the elements one by one from the start. Keep the answer in a variable that starts at -1, which is what we print if X is never found. When X is found, save its index and break, so that the first position is kept:

int pos = -1;
for (int i = 0; i < n; i++) {
    if (a[i] == x) {
        pos = i;
        break;
    }
}

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int x;
    cin >> x;

    int pos = -1;
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            pos = i;
            break;
        }
    }
    cout << pos << "\n";
    return 0;
}

Go through the array from the start and stop at the first element equal to X. If none is found, pos stays -1.

C

Replacement

Changing elements

An element of an array works like a normal variable, so you can assign a new value to it:

a[i] = 1;

Go through the array, replace each element according to its sign, and then print the array. Zeros are neither positive nor negative, so they stay as they are.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    for (int i = 0; i < n; i++) {
        if (a[i] > 0) a[i] = 1;
        else if (a[i] < 0) a[i] = 2;
    }

    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    cout << "\n";
    return 0;
}

Replace positive elements with 1 and negative elements with 2, leave zeros alone, then print the array.

D

Reversing

Going through an array backwards

The last element is at index n - 1 and the first is at index 0. To print the array in reverse, start the loop at n - 1 and count down to 0:

for (int i = n - 1; i >= 0; i--) {
    cout << a[i] << " ";
}

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    for (int i = n - 1; i >= 0; i--) {
        cout << a[i] << " ";
    }
    cout << "\n";
    return 0;
}

Read the array, then print it from the last index down to the first.
