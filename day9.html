Missing Area

Choosing the right type

D = X − A − B − C. The values reach 1018, so use long long.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long x, a, b, c;
    cin >> x >> a >> b >> c;
    cout << x - a - b - c << "\n";
    return 0;
}

D = X − A − B − C, in long long.

B

Unique Game

The largest and the second largest

Two passes: one for the maximum, one for the largest value strictly below it:

long long second = LLONG_MIN;
for (int i = 0; i < n; i++) {
    if (a[i] < first) second = max(second, a[i]);
}

LLONG_MIN is the smallest possible long long. The a[i] < first check skips every copy of the maximum.

Things to watch out for

  • Duplicates: taking the two largest cards fails on 4 4 1.
  • Negatives: initializing second to 0 fails, hence LLONG_MIN.
  • Values reach 1015: long long.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    long long first = LLONG_MIN;
    for (int i = 0; i < n; i++) {
        first = max(first, a[i]);
    }

    long long second = LLONG_MIN;
    for (int i = 0; i < n; i++) {
        if (a[i] < first) second = max(second, a[i]);
    }

    cout << first << "\n" << second << "\n";
    return 0;
}

The maximum, then the largest value strictly below it.

C

Magic Cells

Counting steps in a grid

Moving only down or right, every path from (1, 1) to (i, j) takes exactly (i − 1) + (j − 1) steps, regardless of order.

Without magic cells, the answer is (N − 1) + (M − 1).

Using the magic cells

A magic cell ends the walk the moment you reach it, so the answer is the minimum of:

  • (N − 1) + (M − 1), walking all the way, and
  • (i − 1) + (j − 1) for every magic cell (i, j).

In the sample, (3, 1) is reached in 2 steps.

With 0-indexed loops, cell [i][j] is i + j steps away. No need to store the grid; check each value as it’s read.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    int ans = (n - 1) + (m - 1);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            int cell;
            cin >> cell;
            if (cell == 1) ans = min(ans, i + j);
        }
    }
    cout << ans << "\n";
    return 0;
}

Start from the full walk and take the minimum with every magic cell.

D

Back to School

Trying every pair

Brute force: check every pair with nested loops. Starting j at i + 1 guarantees i ≠ j and visits each pair once:

for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        if (a[j] == x - a[i]) good = true;
    }
}

That’s about N2 / 2 = 5 × 109 checks per test case at N = 105. Too slow.

Binary search for the partner

Each a[i] has exactly one possible partner, x - a[i]. Sort the array and binary search for it (Day 8).

Searching only after index i keeps j ≠ i. a.begin() + i + 1 is the start of that range:

if (binary_search(a.begin() + i + 1, a.end(), x - a[i])) good = true;

Pairs with j < i were already checked when the loop was at j, so nothing is missed. It also prevents pairing an element with itself, e.g. 2 + 2 for {1, 2, 5} and X = 4.

Total: about N log2 N ≈ 1.7 × 106 operations per test case.

Fast input and output

Put these two lines at the top of main. They speed up cin and cout, which matters for inputs this large:

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    // the rest of your code
}

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        int n, x;
        cin >> n >> x;
        vector<int> a(n);
        for (int i = 0; i < n; i++) {
            cin >> a[i];
        }
        sort(a.begin(), a.end());

        bool good = false;
        for (int i = 0; i < n; i++) {
            if (binary_search(a.begin() + i + 1, a.end(), x - a[i])) {
                good = true;
                break;
            }
        }

        if (good) cout << "YES" << "\n";
        else cout << "NO" << "\n";
    }
    return 0;
}

Sort, then binary search for x - a[i] to the right of each i.
