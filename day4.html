A

Palindrome

The while loop

So far, every line of a program ran exactly once. A while loop runs a block of code again and again, as long as its condition is true:

int x = 3;
while (x > 0) {
    cout << x << "\n";
    x--;
}
// prints 3, 2, 1

Before each repetition, the condition x > 0 is checked. If it's true, the block runs; if it's false, the loop ends and the program continues after it. x-- is short for x = x - 1.

Something inside the loop has to change the condition eventually. If x never decreased, the condition would stay true forever and the program would never finish.

Reversing a number

On Day 2 you saw that n % 10 gives the last digit of n, and n / 10 removes it. With a loop, we can repeat this until no digits are left, which takes the digits off n from right to left.

To build the reversed number, start with rev = 0 and attach each digit to its end. Multiplying by 10 shifts every digit one place left and makes room for the new digit:

int rev = 0;
while (n > 0) {
    rev = rev * 10 + n % 10;
    n /= 10;
}

Here's how it runs for n = 160:

nn % 10New rev
16000 × 10 + 0 = 0
1660 × 10 + 6 = 6
116 × 10 + 1 = 61
0Condition is false, loop ends

The leading zero disappears on its own: attaching a 0 to an empty rev just leaves it at 0, and a number never stores leading zeros anyway.

Keeping a copy

A number is a palindrome exactly when it equals its reverse. But the loop above divides n all the way down to 0, so by the time it finishes, the original value is gone. Save a copy before the loop and compare the reverse with that copy.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int original = n;

    int rev = 0;
    while (n > 0) {
        rev = rev * 10 + n % 10;
        n /= 10;
    }

    cout << rev << "\n";
    if (rev == original) cout << "YES" << "\n";
    else cout << "NO" << "\n";
    return 0;
}

Reverse the number digit by digit, print it, then compare it with the saved original. N is at most 107, so the reverse always fits in an int.

B

Factorial

The for loop

Very often, a loop needs a counter that goes through the numbers 1, 2, 3, and so on. A for loop puts everything about that counter on one line:

for (int i = 1; i <= 5; i++) {
    // runs with i = 1, 2, 3, 4, 5
}

The line has three parts, separated by semicolons:

  • int i = 1 runs once, before the loop starts.
  • i <= 5 is checked before every repetition, just like the condition of a while loop.
  • i++ runs after every repetition. It's short for i = i + 1.

Computing a product

To multiply the numbers from 1 to n, keep a running result and multiply it by i on each step. Start the result at 1, since multiplying by 1 changes nothing:

long long f = 1;
for (int i = 1; i <= n; i++) {
    f *= i;
}

This handles 0! = 1 without any special case: when n = 0, the condition 1 <= 0 is false from the start, the loop never runs, and f stays 1.

Factorials grow very fast. 20! = 2,432,902,008,176,640,000, which is about 2.4 × 1018. That's far too big for an int, but it fits in a long long, which goes up to about 9.2 × 1018.

Multiple test cases

Many problems give several inputs in one file. The first number T says how many test cases follow, and you solve each one separately. Put the whole solution inside a loop that runs T times:

int t;
cin >> t;
while (t--) {
    // read one test case, solve it, print its answer
}

while (t--) is a common shortcut. It checks whether t is nonzero and then decreases it by 1, so the loop runs exactly T times.

You don't have to read all the input first. Print each answer as soon as you compute it; the judge only looks at the final output.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        long long f = 1;
        for (int i = 1; i <= n; i++) {
            f *= i;
        }
        cout << f << "\n";
    }
    return 0;
}

For each test case, multiply 1 × 2 × … × N. f must be a long long and must be reset to 1 inside the loop, so each test case starts fresh.

C

1 to N

Using the counter

The counter of a for loop is a normal variable, so you can use it inside the loop like any other. On each step it holds the current number, which here is exactly what needs to be printed.

Solution

Try the problem on Codeforces before revealing the solution.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cout << i << "\n";
    }
    return 0;
}

Loop i from 1 to N and print it on its own line each time.
